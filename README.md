# 💊 PharmaFast – Online Medical Management System

**PharmaFast** is a full-stack **Online Medical Management System** designed to digitize healthcare workflows such as **doctor appointments, medicine ordering, stock management, and emergency support**.  
Built using **Java (JSP & Servlets), JDBC, and MySQL**, the system follows a clean **MVC architecture** and focuses on **real-world healthcare usability**.

---

## 🚀 Project Overview

PharmaFast bridges the gap between patients, doctors, and administrators by providing a unified digital platform that ensures:

- Faster appointment booking  
- Transparent appointment status tracking  
- Secure medicine ordering  
- Real-time stock management  
- Emergency medical access  
- Optional video consultation support  

This project was developed as an **academic + industry-oriented application**, emphasizing **scalability, clean backend logic, and user-friendly UI**.

## 🎯 Key Features

### 👨‍⚕️ Doctor Module
- Secure doctor authentication
- View all patient appointments
- Approve or reject appointment requests
- View patient details
- Start video consultation for approved appointments

### 🧑‍🤝‍🧑 Patient Module
- Patient registration & login
- Book doctor appointments with time slots
- View appointment status (Pending / Approved / Rejected)
- Order medicines online
- View order history
- Join video consultation (for approved appointments)
- Access emergency medical helplines

### 🛠️ Admin Module
- Admin authentication
- View all registered patients and doctors
- Medicine stock monitoring
- Update existing medicine stock
- Add new medicines to inventory
- Low-stock alerts for inventory control

### 🚑 Emergency Module
- National & city-wise medical emergency helplines
- Ambulance and health support numbers
- Click-to-call functionality

---

## 🧠 System Architecture

**Architecture Pattern:** MVC (Model–View–Controller)

- **Model:** Java Beans + JDBC (MySQL)
- **View:** JSP, HTML, CSS
- **Controller:** Java Servlets
- **Server:** Apache Tomcat (Port: 8082)

This ensures:
- Clear separation of concerns  
- Better maintainability  
- Industry-standard backend structure

- Session-based authentication
- Role-based access control
- Server-side validation using Servlets
- SQL Injection prevention via `PreparedStatement`
- Appointment date validation
- Slot conflict prevention logic
